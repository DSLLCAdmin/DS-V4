## 🗂️ **ORGANIZING ALIAS EMAILS (BREAKING OUT):**

### **YES! You CAN Separate Alias Emails in Zoho:**

### **Option 1: Create Filters/Rules (RECOMMENDED)**

**Set up automatic folder organization:**

1. **Go to:** Zoho Mail Webmail: https://mail.zoho.com
2. **Navigate to:** Settings (gear icon) → Filters
3. **Create Filter for admin@:**
   - **Name:** "Admin Emails"
   - **Condition:** "To" contains "admin@darkstreetllc.com"
   - **Action:** Move to folder "Admin" (create folder if needed)
   - **Apply to:** All future emails
   - **Save**

4. **Create Filter for support@:**
   - **Name:** "Support Emails"
   - **Condition:** "To" contains "support@darkstreetllc.com"
   - **Action:** Move to folder "Support" (create folder if needed)
   - **Save**

5. **Create Filter for test@:**
   - **Name:** "Test Emails"
   - **Condition:** "To" contains "test@darkstreetllc.com"
   - **Action:** Move to folder "Test" (create folder if needed)
   - **Save**

**Result:**
- admin@ emails → Auto-moved to "Admin" folder
- support@ emails → Auto-moved to "Support" folder
- test@ emails → Auto-moved to "Test" folder
- All other emails → Stay in main inbox

---

### **Option 2: Use Labels/Tags**

1. **Go to:** Settings → Labels
2. **Create Labels:**
   - "Admin"
   - "Support"
   - "Test"
3. **Set up Auto-Labeling:**
   - **Rule:** "To" contains "admin@darkstreetllc.com" → Label "Admin"
   - **Rule:** "To" contains "support@darkstreetllc.com" → Label "Support"
   - **Rule:** "To" contains "test@darkstreetllc.com" → Label "Test"

**Result:**
- Emails color-coded/labeled by alias
- Still in inbox, but visually separated

---

### **Option 3: Use Zoho's "From Address" Filtering**

1. **Go to:** Settings → Mail → General
2. **Enable:** "Show sender address in email list"
3. **Create views** for each alias address
4. **Filter inbox** by alias address

## 📤 **REPLYING FROM ALIAS ADDRESSES:**

### **When You Reply:**
- **Zoho automatically detects** which alias received the email
- **You can choose** which "From" address to use:
  - Reply as admin@darkstreetllc.com
  - Reply as support@darkstreetllc.com
  - Reply as test@darkstreetllc.com
  - Reply as ariestiger@darkstreetllc.com (alias)

**How to Set Default "From" Address:**
1. **Go to:** Settings → Mail → Composing
2. **Set:** Default "From" address per alias
3. **OR:** Choose per email when replying
