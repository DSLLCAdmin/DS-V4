## 📥 PDF Conversion Instructions

All markdown guides can be converted to clean PDF format:

1. **Run conversion script:**
   ```bash
   node scripts/convert-md-to-pdf.js
   ```

2. **Output location:**
   - `docs/pdf-ready/` directory
   - Clean .txt files ready for PDF conversion

3. **Convert to PDF:**
   - Open .txt files in Microsoft Word or Google Docs
   - Format headers, spacing, fonts as desired
   - Export to PDF
