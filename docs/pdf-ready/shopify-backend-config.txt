Shopify Backend-Only Configuration Guide




🎯 DS LLC Website-First Strategy




Core Architecture
  • DS LLC Website: Primary customer-facing storefront  • Shopify: Backend-only for payments, order tracking, and fulfillment  • No duplicate stores: Shopify remains invisible to customers

Storefront Redirect



Add to theme.liquid

<script>
if (window.location.pathname.includes('/products/')) {
  window.location.href = 'https://darkstreetllc.com/shop';
}
if (window.location.pathname.includes('/collections/')) {
  window.location.href = 'https://darkstreetllc.com/shop';
}
</script>



SEO Redirects



Add to .htaccess or server config

Redirect 301 /products/ https://darkstreetllc.com/shop
Redirect 301 /collections/ https://darkstreetllc.com/shop
Redirect 301 /search https://darkstreetllc.com/shop  8. Testing Configuration
