PRINTFUL PRODUCT CHECKOUT SOLUTION
======================================================================

✅ Printful Product Checkout Solution - DISCOVERED!


Date: October 31, 2025
Status: ✅ SOLUTION FOUND





🎯 Root Cause Identified


Three Critical Factors for Printful Products to Work:  1. ✅ NEW Product Listings (NOT reusing previous product placeholders)  2. ✅ Collection Assignment (Products must be in a published collection)  3. ✅ "DS Website Integration" Publishing Channel (Must be enabled)





✅ Evidence: Streeter Mug (H-06)




What Worked:
  • ✅ NEW product - Created fresh, didn't reuse old placeholder  • ✅ Published with "Home page" collection during initial publish  • ✅ "DS Website Integration" channel enabled  • ✅ Checkout SUCCESS - Product visible in Storefront API and checkoutable



What Didn't Work (Tee/Cap):
  • ❌ Reused existing product entries (T-01, B-08)  • ❌ Published WITHOUT collections (initially)  • ⚠️ "DS Website Integration" status unknown (needs verification)





🔧 Solution Steps for Future Printful Products




Step 1: Create NEW Product in Shopify
  • ❌ DO NOT reuse old product placeholders  • ✅ DO create fresh product entries  • ✅ Assign unique Product ID (H-06, H-07, etc.)



Step 2: Assign to Collection During Publish
  • ✅ When publishing Printful product, look for "Add to collections" option  • ✅ Select "Home page" (or other published collection)  • ⚠️ NOTE: Collections can also be added AFTER publishing (see below)



Step 3: Enable "DS Website Integration" Channel
  1. Go to: Shopify Admin → Products → [Your Product]  2. Click: "Publishing" section (right sidebar)  3. Click: "Manage" or pencil icon  4. Enable: "DS Website Integration" toggle  5. Click: "Done"





🔍 Finding Printful's Collection Assignment Setting




Location 1: During Initial Publish
  • When publishing product from Printful → Shopify  • Look for "Add to collections" checkbox/field at bottom of publish dialog  • Select collection(s) before clicking "Publish"



Location 2: After Publishing (Shopify Admin)
  • Go to: Shopify Admin → Products → [Your Product]  • Scroll to: "Product organization" section (right sidebar)  • Find: "Collections" field  • Click: Search icon or input field  • Select: "Home page" (or desired collection)  • Click: "Save"



Location 3: Printful Dashboard
  • Check: Printful Dashboard → Products → [Your Product]  • Look for: "Shopify Collections" or "Publishing" settings  • May be hidden in: Product settings, Sync options, or Publishing settings





📋 Verification Checklist


After creating a NEW Printful product, verify:  • [ ] Product is NEW (not reusing old placeholder)  • [ ] Product is assigned to "Home page" collection (or published collection)  • [ ] "DS Website Integration" publishing channel is ENABLED  • [ ] Product shows in Storefront API query: node scripts/query-products-via-storefront-api.js  • [ ] Product checkout works: node scripts/test-shopify-checkout.js  • [ ] Product displays correctly on DSLLC website





🔄 Fixing Existing Products (Tee/Cap)




For DarkStreets Tee - V-Neck (T-01) and Cap (B-08):
  1. Add to Collection:  • Shopify Admin → Products → [Product]  • "Product organization" → "Collections"  • Add "Home page" collection  • Save  2. Enable "DS Website Integration":  • "Publishing" section → "Manage"  • Enable "DS Website Integration" toggle  • Click "Done"  3. Test:
   node scripts/query-products-via-storefront-api.js
   node scripts/test-shopify-checkout.js  4. If Still Fails:  • Consider creating NEW products (don't reuse T-01, B-08)  • Use new Product IDs (T-02, B-09, etc.)  • Follow fresh product workflow above





📝 Key Insights




Why NEW Products Work:
  • Old products may have cached/invalid Storefront API state  • Fresh products start with clean API visibility  • No legacy publishing channel conflicts



Why Collections Matter:
  • Printful products require published collections for Storefront API visibility  • Books work WITHOUT collections (different fulfillment provider)  • Collections = Storefront API visibility requirement for Printful



Why "DS Website Integration" Channel:
  • This custom channel may sync products to Storefront API differently  • Enabling it ensures proper API propagation  • May be required for third-party integrations





🚀 Best Practices Going Forward
  1. Always create NEW products for Printful items  2. Always assign to "Home page" collection during publish  3. Always enable "DS Website Integration" channel  4. Test immediately after setup:  • Storefront API visibility  • Checkout functionality  • Website display  5. Document each product with:  • Product ID assigned  • Collection assigned  • Publishing channels enabled  • Test results
