Import Instructions




Step 1: Prepare CSV File
  1. Download template from Shopify admin  2. Fill in product data using the format above  3. Save as CSV with UTF-8 encoding



Step 2: Import Products
  1. Go to: Products → Import  2. Upload CSV file  3. Map columns to Shopify fields  4. Start import



Step 3: Verify Import
  1. Check product count matches expected  2. Verify variant IDs are correct  3. Test product visibility (should be hidden)



Product Configuration




After Import, Configure Each Product
  1. Go to: Products → [Product Name]  2. Set:  • Status: Active  • Visibility: Hidden from search engines  • SEO: Disabled  • Inventory: Track inventory  • Fulfillment: Set appropriate service



Variant Configuration
  1. Set SKU to match DS LLC product ID  2. Set price to match DS LLC price  3. Set inventory to 999 (unlimited)  4. Set fulfillment service per product type
